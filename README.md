# 🎨 AI Prompt Metadata Viewer (Pure x86-64 Assembly)

A lightweight, high-performance native Windows GUI tool for viewing, copying, and saving AI generation parameters embedded within PNG image metadata. Written entirely in raw **x86-64 Assembly (SASM)** with zero external runtime dependencies.  AI was used in the process of creating this.

---

### ✨ Features

* **⚡ Pure Assembly:** Ultra-small binary footprint with zero dependency on heavy frameworks or external runtimes.
* **🖼️ Multi-Engine Detection:** Automatically parses PNG `tEXt` chunks to identify metadata from:
  * **AUTOMATIC1111** (`parameters`)
  * **ComfyUI** (`prompt`)
  * **InvokeAI** (`invokeai_metadata`)
  * **NovelAI** (`Description`)
* **🖱️ Drag & Drop Support:** Drop any PNG image directly onto the application window to load it instantly.
* **📂 File Browser Integration:** Uses native Windows File Dialogs (`comdlg32.dll`) to browse and select images.
* **✨ Built-in Image Renderer:** Previews the loaded PNG image side-by-side using dynamic aspect-ratio scaling via GDI+.
* **📋 Clipboard & Export Options:** One-click copying of raw or JSON-formatted metadata to your clipboard, or exporting straight to a `.txt` file.

---

### 🔧 Building from Source

#### Prerequisites
* **SASM** (SimpleASM IDE configured for 64-bit Assembly)

#### Build Instructions
1. Open `AI-Prompt-Viewer-ASM.asm` inside **SASM**.
2. Select **x64** target mode in the settings.
3. Click **Build / Run** (`F5`) to compile and launch the executable.

---

### 🚀 Usage

1. Launch `AI-Prompt-Viewer-ASM.exe`.
2. **Drag & Drop** a PNG file generated by an AI image generator into the window, or click **Browse Image...**.
3. The detected engine will update, and the parsed prompt/parameters will display in the text field.
4. Click **Copy to Clipboard** to grab the metadata, or **Save to .txt** to save a local text backup.

---

### Can I just download and run this?
Since this is written in Assembly, Windows isn't happy about running this without it being signed.  This makes it more challenging to distribute the executable directly.  It is recommended to compile your own.  It's easy in SASM. :)
